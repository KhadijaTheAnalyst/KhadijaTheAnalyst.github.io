# KhadijaTheAnalyst.github.io

My personal **portfolio website**, built and hosted via GitHub Pages.

## Overview

This site serves as an online portfolio showcasing my data analytics projects, skills, and background. It is built on the **Massively** template by HTML5 UP, customized to reflect my work and professional profile.

## What's Inside

- **About Me** — Background, skills, and current learning journey
- **Projects** — Featured data analytics projects across SQL, Excel, Power BI, Tableau, and Python
- **Contact** — Links to email and LinkedIn for collaboration inquiries

## Built With

- HTML5 / CSS3 / JavaScript
- [Massively Template](https://html5up.net/massively) by HTML5 UP (CCA 3.0 license)
- Hosted on **GitHub Pages**
