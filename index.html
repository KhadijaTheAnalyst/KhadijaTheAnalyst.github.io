🚆 7 YEARS · GTFS DATA · PYTHON
Python GTFS Power BI Open Data Data Storytelling

Did Free Transit Actually Grow Luxembourg's Network?

Analysed 7 years of official GTFS schedule data (2018–2025) from Luxembourg's Open Data Portal to measure the real impact of making public transport free in 2020. Key finding: departures more than doubled (23,549 → 50,691), routes grew by 246, and weekend service expanded ×7.8 , far outpacing 15% population growth.

Python scikit-learn Keras SHAP

Loan Default Prediction: Credit Risk Modeling

Built an end-to-end ML pipeline on 148,670 mortgage loans, going beyond standard accuracy to reason through real data messiness. Distinguished data leakage hiding in missing values vs. genuinely missing data, engineered missingness flags that became the strongest predictors (confirmed via SHAP), and compared three model families with manual threshold tuning. Achieved 89.1% accuracy with 72.7% F1 on Random Forest, with interpretable feature importance analysis.
